개인정보처리방침

shorts-upload · 시행일 2026년 10월 10일

shorts-upload(이하 "이 도구")는 운영자가 자신의 유튜브 채널에 영상을 올리기 위해 직접 만들어 자신의 PC에서만 실행하는 개인용 프로그램입니다. 이 도구는 운영자 외의 사용자를 받지 않으며, 회원가입이나 외부 제공이 없습니다. 이 방침은 이 도구가 구글 사용자 데이터를 어떻게 다루는지 설명합니다.

1. 접근하는 구글 사용자 데이터

이 도구는 운영자가 로그인한 구글 계정에 대해 아래 범위만 요청합니다.

  • youtube.upload — 운영자의 채널에 영상 파일과 제목·설명·태그를 업로드
  • youtube.readonly — 업로드한 영상의 공개 상태와 채널 이름·ID 조회
  • youtube.force-ssl — 업로드한 영상에 운영자 명의로 댓글 작성

위 범위는 모두 운영자 본인 소유 채널에만 사용합니다. 다른 이용자의 채널, 구독자 목록, 시청 기록, 이메일 본문 등 다른 구글 서비스의 데이터에는 접근하지 않습니다.

2. 저장하는 것과 저장 위치

  • 갱신 토큰 — 운영자 PC의 사용자 폴더 (%USERPROFILE%\.volcano\keys\youtube\) 안에 파일로만 저장합니다. 채널마다 한 개씩이며, 다음 업로드 때 다시 로그인하지 않기 위한 용도입니다.
  • 업로드 이력 — 운영자 PC의 로컬 데이터베이스 파일에 영상 제목, 영상 ID, 채널, 올린 날짜, 공개 상태를 기록합니다. 하루 업로드 편수를 세고 같은 영상을 두 번 올리지 않기 위한 용도입니다.

구글 계정의 비밀번호는 다루지 않습니다. 로그인은 구글이 제공하는 OAuth 2.0 화면에서만 이루어지며, 이 도구는 그 결과로 받은 토큰만 받습니다.

3. 외부 전송과 제3자 제공

이 도구는 구글 사용자 데이터를 운영자의 PC 밖으로 보내지 않습니다. 유일한 통신 상대는 구글 API 서버(영상 업로드·조회·댓글)이며, 별도의 서버를 두지 않습니다. 어떠한 제3자에게도 판매·대여·공유하지 않습니다. 광고나 분석 목적으로 사용하지 않으며, 인공지능 모델의 학습에 사용하거나 사용하도록 제공하지 않습니다.

4. 보관 기간과 삭제

토큰과 이력은 운영자가 지울 때까지 PC에 남습니다. 토큰 파일을 지우면 이 도구는 해당 채널에 더 이상 접근할 수 없습니다. 접근 권한은 구글 계정의 보안 > 서드파티 앱 에서 언제든지 철회할 수 있으며, 철회하면 남아 있는 토큰도 즉시 무효가 됩니다.

5. 다루지 않는 것

  • 운영자 외 다른 사람의 개인정보를 수집하지 않습니다
  • 쿠키나 웹 추적 기술을 쓰지 않습니다 (이 웹페이지 포함)
  • 만 14세 미만 아동의 정보를 의도적으로 수집하지 않습니다

6. 구글 API 서비스 사용자 데이터 정책

이 도구가 구글 API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 것은 구글 API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

shorts-upload's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
